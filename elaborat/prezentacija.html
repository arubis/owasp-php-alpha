Што е OWASP Top 10?

  • Open Web Application Security Project
  • Стандардизирана листа на 10 најкритични веб ранливости
  • Ажурирана верзија од 2021 година
  • Индустриски стандард за веб безбедност

Зошто Laravel?

  • Најпопуларна PHP рамка
  • Вградени безбедносни механизми
  • Eloquent ORM (заштита од SQL Injection)
  • CSRF токени (автоматски)
  • Bcrypt хеширање (по default)
  • Middleware систем за access control

A01: Broken Access Control

РАНЛИВО 
// Нема проверка!
public function adminPanel() {
    return User::all();
}
БЕЗБЕДНО 
// Middleware заштита
Route::get('/admin')
  ->middleware('role:admin');

A02: Cryptographic Failures

РАНЛИВО 
// MD5 = слабо!
$hash = md5($password);
БЕЗБЕДНО 
// Bcrypt
$hash = Hash::make($password);

MD5 може да се пробие за секунди со rainbow tables!

A03: SQL Injection

РАНЛИВО 
$sql = "SELECT * FROM users 
WHERE name = '" . $input . "'";

Напад: ' OR '1'='1

БЕЗБЕДНО 
// Eloquent ORM
User::where('name', $input)->get();

Prepared statements автоматски!

A04: Insecure Design

РАНЛИВО 
// 4-цифрен токен
$token = rand(1000, 9999);
// Само 10,000 можности!
БЕЗБЕДНО 
// Криптографски безбеден
$token = Str::random(64);

// + Rate limiting
RateLimiter::hit($key);

A07: Authentication Failures

РАНЛИВО 
Auth::login($user);
// Session fixation можен!
БЕЗБЕДНО 
Auth::login($user);
$request->session()->regenerate();

A08-A09: Integrity & Logging

A08: File Upload

$request->validate([
    'file' => 'required|file|max:2048|mimes:jpg,png,pdf'
]);

A09: Security Logging

Log::warning('Failed login', [
    'ip' => $request->ip(),
    'username' => $username
]);

A10: SSRF

РАНЛИВО 
// Без валидација!
Http::get($userUrl);

// Може да пристапи до:
// localhost, AWS metadata...
БЕЗБЕДНО 
$allowed = ['api.github.com'];
if (!in_array($host, $allowed)) {
    abort(403);
}
