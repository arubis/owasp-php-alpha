1. Вовед

OWASP (Open Web Application Security Project) Top 10 претставува стандардизирана листа на најкритичните безбедносни ризици за веб апликации. Оваа листа се ажурира периодично и служи како водич за развивачи и безбедносни експерти при идентификација и митигација на ранливости.

Целта на овој проект е да се демонстрира:

  • Како програмерите можат (намерно или ненамерно) да создадат ранливости
  • Вградените безбедносни механизми кои Laravel рамката ги нуди
  • Споредба меѓу "ранлива" и "безбедна" имплементација за секоја ранливост
  • Евалуација на алатки за скенирање ранливости

Зошто Laravel?

Laravel е најпопуларната PHP рамка со вградени безбедносни механизми:

OWASP Ранливост Laravel Заштита

2. Потребен хардвер/софтвер

Минимални барања

  • RAM: 4GB (препорачано 8GB)

3. Инсталација и подготовка

Чекор 1: Инсталација на PHP (Windows)

  1. Преземете PHP од windows.php.net
  2. Екстрактирајте во C:\php
  3. Додадете во PATH: System Properties → Environment Variables → Path → Add C:\php
  4. Овозможете екстензии во php.ini:
extension=openssl
extension=mbstring
extension=pdo_sqlite
extension=fileinfo
extension=curl

Чекор 2: Инсталација на Composer

# Преземете composer.phar
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"

Чекор 3: Клонирање на проектот

# Клонирај го репозиториумот (или преземи ZIP)
git clone [repository-url]
cd owasp-top10-php-training-app

Чекор 4: Инсталација на зависности

# Инсталирај Laravel зависности
composer install

# Копирај .env фајл
copy .env.example .env

# Генерирај application key
php artisan key:generate

Чекор 5: Подготовка на база

# Креирај SQLite база и табели
php artisan migrate

# Внеси тест податоци
php artisan db:seed

Чекор 6: Стартување на серверот

php artisan serve
✓ Апликацијата е достапна на: http://localhost:8000

Кредeнцијали за логирање:
  • Admin: admin / admin123
  • User: user / user123

4. OWASP Top 10 ранливости

A01: Broken Access Control

Оваа ранливост се јавува кога апликацијата не ги проверува правилно корисничките привилегии пред да дозволи пристап до ресурси.

РАНЛИВО

// Нема проверка на улога!
public function vulnerable() {
    $users = User::all();
    return view('admin', compact('users'));
}

Секој најавен корисник може да пристапи до admin панелот.

БЕЗБЕДНО

// Route со middleware
Route::get('/admin', [Controller::class, 'secure'])
    ->middleware('role:admin');

// Middleware проверува улога
if ($user->role !== 'admin') {
    abort(403);
}

A02: Cryptographic Failures

Користење на слаби криптографски алгоритми за хеширање на лозинки.

РАНЛИВО

// MD5 е СЛАБ за лозинки!
$hash = md5($password);
$hash = sha1($password);

MD5/SHA1 може да се пробијат за секунди со rainbow tables.

БЕЗБЕДНО

// Laravel Hash facade (bcrypt)
$hash = Hash::make($password);

// Верификација
if (Hash::check($password, $hash)) {
    // Точна лозинка
}

A03: Injection (SQL Injection)

Директно вметнување на кориснички внес во SQL барања без санитизација.

РАНЛИВО

// String concatenation = SQL Injection!
$query = "SELECT * FROM products 
          WHERE name LIKE '%" . $search . "%'";
DB::select($query);

Напад: ' OR '1'='1 враќа сè!

БЕЗБЕДНО

// Eloquent ORM - автоматски prepared statements
Product::where('name', 'like', "%$search%")->get();

// Или Query Builder
DB::table('products')
  ->where('name', 'like', "%$search%")
  ->get();

A04: Insecure Design

Лош дизајн на безбедносни механизми, како предвидливи токени за ресетирање лозинка.

РАНЛИВО

// 4-цифрен токен = 10,000 можности
$token = rand(1000, 9999);

// Без rate limiting
// Напаѓачот може да brute-force за минути

БЕЗБЕДНО

// Криптографски безбеден токен
$token = Str::random(64);

// Rate limiting
if (RateLimiter::tooManyAttempts($key, 5)) {
    return 'Too many attempts';
}
RateLimiter::hit($key, 60);

A05: Security Misconfiguration

Погрешна конфигурација која изложува осетливи информации.

РАНЛИВО

# .env во production
APP_DEBUG=true  # Изложува stack traces!

// Изложување на config
return [
    'app_key' => config('app.key'),
    'db_password' => config('database.password'),
];

БЕЗБЕДНО

# .env во production
APP_DEBUG=false
APP_ENV=production

// Генерички error message
try {
    // операција
} catch (Exception $e) {
    Log::error($e->getMessage());
    return 'An error occurred';
}

A06: Vulnerable and Outdated Components

Користење на библиотеки со познати безбедносни ранливости.

Алатки за проверка

# Composer audit (вграден)
composer audit

# Snyk
snyk test

# Roave Security Advisories (спречува инсталација на ранливи пакети)
composer require --dev roave/security-advisories:dev-latest

A07: Identification and Authentication Failures

Session fixation напад - кога session ID не се регенерира по најава.

РАНЛИВО

// Без session regeneration
Auth::login($user);
// Session ID останува ист!
// Напаѓачот може да го искористи

БЕЗБЕДНО

Auth::login($user);
// Регенерирај session ID
$request->session()->regenerate();

// При logout
Auth::logout();
$request->session()->invalidate();
$request->session()->regenerateToken();

A08: Software and Data Integrity Failures

Upload на фајлови без валидација на тип и содржина.

РАНЛИВО

// Нема валидација!
$file = $request->file('upload');
$file->store('uploads');
// Може да се upload-ира PHP shell!

БЕЗБЕДНО

$request->validate([
    'file' => [
        'required',
        'file',
        'max:2048',  // 2MB
        'mimes:jpg,png,pdf'
    ]
]);

// Random filename
$filename = Str::uuid() . '.' . $ext;

A09: Security Logging and Monitoring Failures

Без логирање на безбедносни настани, нападите остануваат незабележани.

РАНЛИВО

// Без логирање
if (!Auth::attempt($credentials)) {
    return back();
}
// Brute force напад не се детектира!

БЕЗБЕДНО

if (!Auth::attempt($credentials)) {
    Log::warning('Failed login', [
        'username' => $request->username,
        'ip' => $request->ip(),
    ]);
    
    AuditLog::create([
        'action' => 'failed_login',
        'ip_address' => $request->ip(),
    ]);
}

A10: Server-Side Request Forgery (SSRF)

Серверот прави HTTP барања до произволни URL-а без валидација.

РАНЛИВО

// Без валидација!
$url = $request->input('url');
$response = Http::get($url);

// Напаѓачот може да пристапи до:
// - http://localhost/admin
// - http://169.254.169.254/ (AWS metadata)

БЕЗБЕДНО

$allowedDomains = ['api.github.com', 'httpbin.org'];
$host = parse_url($url, PHP_URL_HOST);

if (!in_array($host, $allowedDomains)) {
    abort(403, 'Domain not allowed');
}

// Блокирај приватни IP адреси
if ($this->isPrivateIp($ip)) {
    abort(403);
}

5. Евалуација на Security скенери

SAST (Static Application Security Testing)

Алатка Тип Цена Ефикасност
Composer Audit Dependency Scanner Бесплатно ⭐⭐⭐⭐⭐
PHPStan Static Analysis Бесплатно ⭐⭐⭐ (не е security-focused)
Snyk SAST + Dependencies Free tier + Paid ⭐⭐⭐⭐
SonarQube SAST Community (free) ⭐⭐⭐⭐

DAST (Dynamic Application Security Testing)

Алатка Тип Цена Ефикасност
OWASP ZAP DAST Бесплатно ⭐⭐⭐⭐⭐
Burp Suite DAST + Manual Community (free) / Pro ($449/год) ⭐⭐⭐⭐⭐
Nikto Web Scanner Бесплатно ⭐⭐⭐

Препорачани команди

# Composer audit - проверка на зависности
composer audit

# OWASP ZAP (Docker)
docker run -t owasp/zap2docker-stable zap-baseline.py -t http://localhost:8000

# PHPStan
composer require --dev phpstan/phpstan
vendor/bin/phpstan analyse app

6. Заклучок

Овој проект демонстрира како OWASP Top 10 ранливостите се манифестираат во реални Laravel апликации и како правилно да се користат вградените безбедносни механизми на рамката.

Клучни заклучоци

  • Laravel обезбедува одлични вградени заштити - Eloquent ORM, Hash facade, Middleware, CSRF tokens
  • Ранливостите се резултат на заобиколување на овие заштити - raw SQL queries, md5(), итн.
  • Комбинација на SAST и DAST алатки е најефективна за откривање ранливости
  • Редовно ажурирање на зависности е критично (composer audit)
